# 中文牙科子集内容级检测报告

> 结论一句话：**`data/cn_dental/` 里约 35%–42% 的题不是牙科内容，而是被打上「口腔医学」学科标签的通科医学题（药理学 / 儿科学 / 妇产科 / 内科学 / 统计学 / 卫生法规 / 医学伦理 / 传染病学等）。**
> README / PLAN 里「中文牙科用学科字段『口腔医学』，100% 可靠、无 oral 误判风险」这一说法**不成立**。

---

## 1. 检查方法（可复现）

- 数据：`data/cn_dental/{train,val,test}.jsonl`（共 830 题：580/125/125），由
  `data/prepare_cn_dental.py` 按 `Medical Discipline == "口腔医学"` 从 CMExam 全科拆出。
- 检测工具：`data/check_cn_dental_content.py`（本报告新增，可重跑）。
- 对每题拼接 **题干 + 选项**，做**内容级**判定（刻意忽略学科字段），命中任一即视为「牙科」：
  1. **C1 中文强牙科关键词**：龋 / 牙髓 / 牙周 / 牙体 / 牙槽 / 牙龈 / 釉质 / 牙本质 / 根管 /
     窝沟 / 窝洞 / 颌 / 颞下颌 / 口腔 / 腭 / 义齿 / 正畸 / 咬合 / 银汞 / 固定桥 / 阿弗他 /
     白斑 / 舌癌 / 三叉神经 / 面神经 …（完整清单见脚本顶部 `CN_STRONG`，只收医学语境下
     **几乎必然牙科**的词；故意排除歧义词「口/舌/唇/面/种植/修复/冠」）。
  2. **C3 英文 R1/R2 关键词**：复用 `data/dental_filter.py`（防英文题混入）。
- 内容级**零命中** → 判为「仅靠学科字段、疑似非牙科通科题」。
- 交叉验证：再用 `Clinical Department`（临床科室）字段二次判定——内容无牙科词、且科室为
  内科/传染科/妇产科/外科/儿科/精神科/皮肤科等**明显非口腔科室**的题，视为高置信非牙科。

## 2. 结果

| 集合 | 总题数 | 内容无牙科词 | 占比 | 其中科室明显非口腔（高置信非牙科） | 「不符合」科室（统计/伦理/法规等，也非牙科） |
|---|---|---|---|---|---|
| train | 580 | 240 | 41% | 158 | 43 |
| val   | 125 | 52  | 42% | 33  | 13 |
| test  | 125 | 49  | 39% | 25  | 17 |

- 三集合计：830 题中约 **341 题内容无牙科词（41%）**；其中高置信非牙科（非口腔科室）约
  **216 题（26%）**，再加上「不符合」科室的通科题（统计/伦理/法规，约 73 题），
  **保守估计非牙科 ≈ 290 题（35%）**，上限 ≈ 341 题（41%）。
- 即使按最保守口径（只算「非口腔科室 + 无牙科词」），污染比例也 ≥ 26%。

## 3. 典型非牙科例子（摘录，均被打 `Medical Discipline=口腔医学`）

| 题目 | 实际科室 | 真实学科 |
|---|---|---|
| 磺胺药抗菌机制是 | 内科 | 药理学 |
| 粗略推算儿童平均身高公式… | 儿科 | 儿科学 |
| 6个月以内佝偻病患儿多见的骨骼系统改变 | 儿科 | 儿科学 |
| 卡介苗（BCG）被用于治疗膀胱癌属于 | 肿瘤科 | 免疫治疗 |
| 患者女性…经期延长…基础体温单相…排除宫体癌后 | 妇产科 | 妇产科学 |
| 狂犬病病毒的基因组结构为 | 传染科 | 微生物学 |
| 卡特尔人格因素问卷，将人格因素分为 | 精神科 | 心理学 |
| 医疗保健机构严禁采用技术手段进行胎儿… | — | 卫生法规 |
| 统计表中的数字用什么表示 | — | 医学统计学 |
| 噻嗪类利尿药引起电解质紊乱可发生 | 内科 | 药理学 |
| 国家提倡自愿献血的健康公民是 | — | 卫生法规 |

这些题**没有任何牙科关键词**，属于口腔执业医师资格考试必考的通科医学内容，但对本实验
「牙科 vs 非牙科」的划分而言是**污染**。

## 4. 结论

1. **`Medical Discipline == "口腔医学"` 不是可靠的牙科过滤器**。CMExam 的「口腔医学」是
   口腔执业医师的**整卷学科分类**，包含大量基础医学/临床医学/药理学/儿科学/妇产科学/
   卫生法规/医学伦理/统计学通科题。
2. `data/cn_dental/` 约 **35%–42% 为非牙科通科题**（保守 ≥26%）。
3. 现有 `data/check_dental_subset.py` 只查「学科字段 + 英文关键词」，对中文牙科会**误判为
   全部 PASS**（因为每题的学科字段都是「口腔医学」），无法发现上述污染——需要本报告的内容级检测。

## 5. 建议与影响

- **训练影响**：用污染的 580 题训练「中文牙科」模型，实际学的是约 60% 牙科 + 40% 通科，
  会**稀释牙科信号**，且「中文牙科学生超越教师」的结论不再能解释为纯牙科能力。
- **建议**：按内容级关键词重筛（`data/prepare_cn_dental_clean.py`），产出 `cn_dental_clean/`
  纯牙科子集后再训练；本报告的训练已改用 `cn_dental_clean`。
- **说明**：内容级重筛是高精度、偏保守（会同时剔除个别「无关键词但确实是牙科」的题，
  例如靠「口腔科」科室+上下文才能判断的少量题），这是可接受的取舍，且逐题可复核。

## 6. 如何复核

```bash
# 重跑内容级检测（应输出本报告的数字）
python3 data/check_cn_dental_content.py data/cn_dental --report reports/cn_dental_content_report.md

# 逐题命中明细（含命中了哪个词）
python3 data/check_dental_subset.py data/cn_dental/test.jsonl --detail reports/cn_dental_test_detail.txt
```
