# 中文牙科子集重筛（扩充关键词 + 口腔科科室信号）报告

> 任务3：扩充中文关键词表 → 重筛 → 人工复核 52 道边界题 → 更大干净集重训。
> 日期：2026-09-01

---

## 0. 一句话结论

中文牙科「干净」子集从 **489 题**（train 340 / val 73 / test 76）扩到 **545 题**
（train 381 / val 80 / test 84），多回收 **56 题真牙科**（52 道「口腔科但关键词未覆盖」的边界题 + 4 道关键词扩充后新命中的题），同时排除了 1 道误收的内科题（Osler 结）。

---

## 1. 背景：原来的过滤器漏了什么

原 `data/cn_dental/`（830 题）按学科字段 `Medical Discipline == "口腔医学"` 拆分，
经内容级检测发现 **35%–42% 非牙科通科题**（289 题高置信）。原 `prepare_cn_dental_clean.py`
用「内容级强牙科关键词」重筛（高精度、偏保守），得到 489 题干净集。

但保守关键词表**漏掉了 52 道真牙科题**——它们 Clinical Department 都是「口腔科」，
只是用了关键词表没覆盖的专业术语（舌下神经 / 腮腺 / 卡环 / 冠桩 / 活髓切断术 / 塞治剂 /
Kennedy 分类 / 印模材料 / 腺泡细胞癌 / 沃辛瘤 / 鳃弓 / 甲状舌管囊肿 …）。

## 2. 人工复核 52 道边界题（全部读完，逐题判定）

52 道「口腔科但内容无关键词」的题，逐题复核结论：**52 道全部是真牙科**，分布在：

| 范畴 | 典型题 | 缺失的关键词 |
|---|---|---|
| 口腔解剖/舌 | 舌下神经切断后、轮廓乳头、舌垂直肌、舌组织层次 | 舌下神经/舌乳头/舌肌 |
| 口腔颌面外科 | 颌骨骨髓炎、唇痈/海绵窦、鳃裂囊肿、腮腺扪诊、涎瘘、翼外肌痉挛、关节盘前移位 | 骨髓炎/唇痈/鳃裂/腮腺/涎瘘/翼外肌/关节盘 |
| 口腔修复 | Kennedy 分类、卡环隙卡沟、冠桩直径、印模材料、缩合型硅橡胶 | Kennedy/卡环/冠桩/印模/硅橡胶 |
| 牙体牙髓 | 活髓切断术、酚醛树脂塑化、放射性骨坏死 | 活髓切断术/塑化 |
| 牙周 | 塞治剂、洗必泰含漱液 | 塞治剂/含漱/洗必泰 |
| 口腔黏膜/病理 | 地图舌、萎缩性舌炎、口角炎、基底细胞腺瘤、腺泡细胞癌、沃辛瘤 | 舌炎/口角炎/腺瘤/腺泡细胞癌/沃辛瘤 |
| 胚胎发育 | 原发性上皮带、球状突、Kennedy 牙列缺损 | 牙胚/球状突/牙列缺损 |
| 颞下颌关节 | 开口度/开口受限、翼外肌痉挛 | 开口度/翼外肌 |

> 少量「头颈解剖/消毒」题（颈深筋膜层次、预清洁浸泡溶液）属口腔医师考试范围（口腔颌面外科/感染控制），
> 按「口腔医学」宽口径保留；若按「牙/齿/颌本体」严格口径可再剔，见 §6。

## 3. 改动

### 3.1 扩充中文关键词表（`data/check_cn_dental_content.py` 的 `CN_STRONG`）
新增 ~90 个专业术语，分 12 组（舌/口腔黏膜病/牙周/修复印模/牙体牙髓/唾液腺/颌面外科囊肿肿瘤感染/
颞下颌关节/胚胎牙胚/组织病理）。**刻意收窄了 4 个歧义词**：
- 裸「红斑狼疮」→ 只保留「盘状红斑狼疮」（排除「系统性红斑狼疮」内科题）；
- 裸「氯己定」→ 只保留「洗必泰」「含漱」（排除皮肤消毒题）；
- 裸「腺泡」→ 只保留「腺泡细胞癌」（「唾液腺」已覆盖舍格伦综合征病理题）；
- 裸「失活」→ 删除（歧义：酶失活等）。

### 3.2 增加「口腔科」临床科室信号（`dental_signal`）
`Clinical Department == "口腔科"` 经复核可靠（52/52 真牙科），作为关键词之外的**第二信号**，
专门回收「口腔科但关键词未覆盖」的边界题。综合信号：
```
dental_signal(record) = content_signal(record)   # C1 中文关键词 + C3 英文 R1/R2
                      + dept_signal(record)       # D3 Clinical Department == 口腔科
```
`data/prepare_cn_dental_clean.py` 改用 `dental_signal` 重筛。

## 4. 重筛结果

| 集合 | 原 830 | 旧干净 489 | 新干净 545 | 变化 |

| train | 580 | 340 | 381 | +41 |

## 5. 对训练/结论的影响

- 新干净集 test 84 题，**每 1 题 ≈ 1.19pp**（100/84），噪声比旧 76 题（1.32pp/题）略小。
- 训练集从 340 → 381 题，仍是小样本（中文牙科数据生态受限的客观现实）。
- 旧结果（学生 79.38% / test 76 题）与教师 86.84%（同 76 题）不可直接沿用，
  需在新 84 题上重跑教师基线 + 重训学生后重新判定「学生是否超越教师」。
