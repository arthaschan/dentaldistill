# 消融实验（ablation/）

> 目标：探索默认参数（α=0、rank16、lr 1e-4、1 epoch）是否最优，验证"参数不是拍脑袋定的"。

## 消融维度

| 维度 | 默认值 | 对比取值 | 说明 |
|---|---|---|---|
| α（KL 权重） | 0.0 | 0.0 / 0.15 / 0.35 | 验证"纯标准答案监督是否优于加教师软标签" |
| LoRA rank | 16 | 8 / 16 / 64 | 秩的影响 |
| 学习率 | 1e-4 | 1e-4 / 3e-4 | 学习率敏感性 |
| epoch | 1 | 1 / 3 | 训练轮数（是否过拟合/饱和） |

## 主消融场景

以 **中文牙科（Qwen3-32B，data/cn_dental）** 为主场景（数据小、跑得快、结论最硬）；
可换 **中文全科（Qwen2.5-14B）** 做规模对照。

## 运行

```bash
bash ablation/run_ablation.sh           # 在 cn_dental 上跑 α/rank/lr/epoch 网格
```

每个配置独立训练 + 在 test 上评估，结果汇总到 `ablation/results_*.tsv`。

## 历史结论（mentalDistill，供参考，需本仓库重跑确认）

- α：KL 权重越高越差，α=0 最优（21_ablation 结论：α=0 canonical 89.14% > α=0.35 88.67%）。
- rank：rank 64 过拟合、rank 128 发散；rank 16 稳定。
- epoch：3 epoch 饱和，不继续涨。
- 结论方向：默认参数（α=0/rank16/lr1e-4/1ep）即是或接近最优，消融用于**证实而非重新调参**。
